# Reproducible Bacterial Genome Assembly and Annotation

## Overview
This project performs a reproducible de novo genome assembly and annotation
of a bacterial genome from publicly available whole-genome sequencing (WGS)
reads.
The goal is to assemble a bacterial genome from raw sequencing reads and
annotate its gene content, then compare basic assembly statistics against
the species' known reference genome.

## Research Question
How well does a de novo assembly built from a subset of public WGS reads
compare to the reference genome, in terms of assembly contiguity and
predicted gene content?

## Data
- Reference genome: *Mycobacterium tuberculosis* H37Rv, NCBI accession NC_000962.3
- Sequencing reads: SRA run SRR12345678 (paired-end Illumina WGS). Only the
  first 1,000,000 spots are used (`fastq-dump -X 1000000`), so the subset
  may not represent the whole run.

The input data are not included in this repository. The `run_analysis.sh`
script downloads the reference and reads directly from NCBI/SRA.

## Software
The analysis uses:
- SRA Toolkit (fastq-dump) 3.1.1
- SKESA 2.4.0
- SeqKit 2.8.2
- Prokka 1.14.6
- curl

The computational environment is specified in `environment.yml`.

## Installation
Create the Conda environment:
```
conda env create -f environment.yml
```

Activate the environment:
```
conda activate assembly-annotation
```

## Running the Analysis
Run the complete analysis with:
```
./run_analysis.sh
```

The script will:
1. Download the reference genome from NCBI.
2. Download the first 1,000,000 read spots of the SRA run.
3. Assemble the reads into contigs using SKESA.
4. Generate assembly statistics for both the assembly and the reference using SeqKit.
5. Annotate the assembly using Prokka.
6. Calculate SHA256 checksums for the input data and output files.

## Outputs
The analysis generates:
```
out/
├── assembly.fasta
├── assembly_stats.tsv
├── ref_stats.tsv
├── prokka_summary.txt
├── prokka_annotation.gff
└── prokka_proteins.faa
```

`assembly.fasta` contains the de novo genome assembly produced by SKESA.
`assembly_stats.tsv` and `ref_stats.tsv` contain contiguity statistics
(contig count, total length, N50, GC%) for the assembly and the reference
genome respectively, generated using SeqKit.
`prokka_summary.txt`, `prokka_annotation.gff`, and `prokka_proteins.faa`
contain the gene-content summary, full gene annotation, and predicted
protein sequences generated by Prokka.

## Methods
Paired-end Illumina reads were downloaded from the SRA run listed above,
limited to the first 1,000,000 spots. Reads were assembled de novo using
SKESA v2.4.0 with default parameters. Assembly contiguity was assessed
using SeqKit v2.8.2 and compared against the reference genome's own
statistics. The resulting assembly was annotated using Prokka v1.14.6,
which predicts protein-coding, tRNA, and rRNA genes and reports a summary
gene count.
SHA256 checksums were calculated for the downloaded data, the assembly, and
all analysis outputs to allow verification of file integrity and
reproducibility.

## Reproducibility
After running the analysis, file integrity can be checked with:
```
sha256sum -c CHECKSUMS.txt
```
A successful reproduction should report `OK` for each file listed in
`CHECKSUMS.txt`.
